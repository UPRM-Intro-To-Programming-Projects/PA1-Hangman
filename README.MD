## 📌 Overview
Welcome to Project Assignment 2: Hangman!

In this assignment, you will be completing a web-based Hangman game built with Python and Flask. The game randomly selects a hidden word and challenges the player to guess it one letter at a time before running out of attempts. Some parts of the codebase are intentionally incomplete — this is where you come in.

This assignment focuses on reading existing code, completing missing logic functions, and understanding how a Flask web application manages state and handles HTTP requests.

## ⚙️ Setup
### 📦 Required Package

This project requires Flask.

Install it using the following command:

    pip install flask

Or install it via PyCharm → Python Packages, as done in PA0.
